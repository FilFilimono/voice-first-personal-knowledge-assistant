# Данные тестов

Здесь два разных сорта файлов, и путать их нельзя.

## Что лежит в git

| Файл | Что внутри |
|---|---|
| `neutral_embeddings.json` | настоящие ответы `gemini-embedding-001` и `gemini-embedding-2` на трёх **нейтральных** текстах (погода, хлеб, векторный индекс) плюс один запрос |

Тексты нейтральные намеренно. Эти фикстуры нужны, чтобы проверять **нормы**
вектора и разбор ответа провайдера, а норма от содержания не зависит:

```
gemini-embedding-001, срез 768 → норма ≈0.58
gemini-embedding-2,   срез 768 → норма  1.0
```

Придуманный вектор проверял бы представления автора о провайдере, а не
провайдера, — поэтому ответы настоящие. Но архива в них нет ни строчки.

## Чего в git нет и не будет

| Файл | Что внутри | Кто создаёт |
|---|---|---|
| `archive_cache.json` | тексты всех записей архива | `tests/archive.py` при прогоне |
| `archive_vectors.json` | их вектора и вектора тестовых запросов | там же, досчитывается по мере надобности |

**Архив в репозиторий не попадает** — [ADR-0002](../../docs/adr/0002-privacy.md),
дополнение от 19 августа 2026. Git отличается от остальных точек выхода тем,
что опубликованное не отзывается: у провайдера можно удалить аккаунт,
из разошедшейся истории коммитов — нет.

Вектора попадают под тот же запрет, хотя выглядят безобидно: ключом кэша
служит сам текст записи, то есть файл векторов — это тот же архив в другом виде.

Оба файла перечислены в `.gitignore` рядом.

## Как это работает

`tests/archive.py` читает записи из **живой базы** в момент прогона и кладёт
их в кэш. Тесты просят фикстуру `archive` и обращаются к записям **по номеру**,
а не по тексту:

```python
def test_office_voice_is_understood(archive: list[Entry]) -> None:
    parsed = _parse(archive, OFFICE_VOICE)  # OFFICE_VOICE = 26
```

Так одновременно выполняются два правила проекта: «данные для тестов берутся
из базы, а не из головы» (`status.md`, после дыр 16 и 18 августа) и «архив
наружу не уходит». Правило про базу от этого даже окрепло — скопировать
в тест «похожую» строку теперь физически негде.

Перечитать кэш руками:

```
uv run python -m tests.archive
```

## Цена, названная вслух

**Нет базы и нет кэша — тесты на живой речи скипаются.** На чистой машине
и в CI они не проверяют ничего. Пропущенный тест зелёным не считается,
и заметить это можно только по счётчику `skipped` в конце прогона —
поэтому сообщение о пропуске говорит, что делать.

Это ослабление того самого набора, который ловил дыры Фазы 1. Обмен принят
сознательно: архив в публичной истории git необратим, пропущенный тест — нет.
